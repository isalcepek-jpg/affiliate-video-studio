# ISAL NOVA v10
ISAL NOVA prototype with:
- Multiple AI model personas (male/female profiles)
- Multiple voice profiles
- Working language selector with saved preference
- Dark and Light themes with saved preference
- Privacy & Data guidance
- About page explaining ISAL = Intelligent System for Adaptive Learning
- Cinematic AI Core intro
- Chat, Research, Create, Agent, AI Live, Build With Me, Projects, Memory, Skills, Scheduled, Library, Settings, Profile
Note: model personas and voice profiles are UI selections until connected to real AI/voice backends.


## v10 fixes
- Dark theme now applies to the entire app/page background and panels, not only selected components.
- Language switching is centralized and updates navigation, headings, buttons, settings labels, privacy/about text, and other supported UI strings together.
- Language and theme remain persisted with localStorage.
